### 5.1 Medium

## 6. Hot-path checklist (актуальное поведение по коду)

| Шаг | OpenSea LIVE mint | Raw sniper |
|-----|-------------------|------------|
| Gate | `gate_live` (typed LIVE если `require_live_confirm`) ✅ | `gate_live` ✅ |
| Auth | SIWE + encrypted cache flush once; per-wallet proxy ✅ | N/A |
| Wait open | Wall-clock; prefetch calldata T−5s (`mint.rs:1697`), nonce refresh T−2s (`:1758`); tighter poll near open | pre-sign все T−5s → ms-spin до `at_time` |
| Gas | LIVE всегда fixed-gas (`force_fixed_gas=true`, `mint.rs:1928-1932`), L2-floor | hard `gas_limit` (default 650k), без estimate @T0 |
| Fees | `fee_ceiling = 4× max_fee` @spawn (`:1920`); underpriced sleep+ceiling; RBF ceiling | `FeeRefreshMode` (default MainnetOnly); re-sign если fees выросли; **M6:** тихий 1 gwei fallback при сбое `fee_history` |
| Send | race multi-RPC (`send_raw_transaction_report`) / Flashbots (mainnet) — **M4:** await по индексу, без per-send timeout; **M1:** без proxy | parallel `eth_sendRawTransaction`, receipts off hot-path |
| Confirm | multi-hash RBF poll, все hash (`rpc.rs:790-839`); `success = status==1`; **SENT≠success** ✅ | receipt wait |

## 10. Кратко для оператора

1. **Новых критичных/high-дыр нет.** Wave A/B/C реально закрыты в коде (LIVE-гейт, redaction, Zeroizing, BusyGuard, proxy-parse, vault-сообщения) — подтверждено, 188 тестов зелёные.
2. **Почини CI:** `clippy --all-targets -D warnings` падает на одной строке теста (`proxy.rs:480`) — CI-гейт сейчас красный. 1 строка (PR-D1).
3. **Sweep/Disperse:** нет защиты от адреса `0x0` — опечатка = необратимая потеря. Добавить guard (PR-D2). Пока — трижды проверяй destination.
4. **Прокси:** OpenSea-auth проксируется, а **RPC-отправка транзакций идёт с реального IP** — RPC-провайдер видит все burner-кошельки с одного IP. Реши: проксировать RPC или принять как есть (PR-D3).
5. **Latency:** race-send ждёт узлы по порядку без таймаута — зависший первый RPC крадёт до 30s. Чинится вместе с прокси (PR-D3).
6. **Секреты:** полный Alchemy-ключ нигде не утекает (авто-ревью преувеличило); в логах/экспортах — только укороченный URL (последние 8 символов). Прокси-пароли видны в форме Settings — не шарь скриншоты.
7. **Политика соблюдена:** телеметрии/облачных вызовов нет; success = on-chain CONFIRMED, не SENT; ключи зашифрованы (AES-GCM/PBKDF2 600k).
8. Остальное — hardening (Wave D): OpenSea `to`-валидация, gas-cap в sweep, тихий fee-fallback, мелкие панк-края.
