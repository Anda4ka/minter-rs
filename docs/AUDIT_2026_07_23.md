## 2. Что уже сильно (не ломать)

1. **Vault** — AES-256-GCM, 600k PBKDF2, salt+nonce, atomic write (+ Windows bak), `Zeroizing` на decrypt path.
2. **Session::Debug** — password / keys / Alchemy / env **не** печатаются.
3. **Amount path** — `eth_to_wei` / `decimal_to_units` без f64; 0.08 ETH exact.
4. **Fee bumps** — `bump_fee_bps` integer bps (не f64).
5. **Success = on-chain confirm** — SENT ≠ success; multi-hash RBF poll.
6. **Concurrency gate** — `mint_running` на mint / raw / disperse / multicall / sweep.
7. **Cancel** — `AtomicBool` в wait/attempt loops.
8. **safe_truncate** — нет panic на UTF-8 в логах ошибок.
9. **Proxy sticky** — `WalletAuth.proxy_url` с auth time.
10. **Fee refresh sniper** — `FeeRefreshMode` (default MainnetOnly).
11. **CSP** в Tauri не `null`; capabilities минимальные.
12. **Public/** secrets gitignored; `-MakeZip` allowlist.

## 3. Findings (верифицированы по коду)

Severity: **C** critical / **H** high / **M** medium / **L** low / **N** note.

### 3.1 High

| ID | Тема | Где | Детали | Риск |
|----|------|-----|--------|------|
| **H1** | LIVE confirm только в UI | `api.rs` (`_confirm` ignored), `lib.rs` comment L704–705, `app.js` Tasks Start | Core **намеренно** игнорирует `confirm`. Gate — только webview modal. DevTools / другой IPC-клиент / баг UI → live mint без «type LIVE». `require_live_confirm` не enforced в Rust. | Случайный/обходной live spend |
| **H2** | LIVE confirm fail-open | `ui/app.js` ~5038–5064 | `try { needLive = invoke(...) ; modal } catch { console.warn }` — при ошибке invoke/modal **старт продолжается**. Safety gate fail-open. | Live start без подтверждения при сбое IPC |
| **H3** | Underpriced retry: no sleep, fee×1.15 | `mint.rs` ~2621–2626 | В отличие от nonce-too-low (sleep + burst), underpriced делает `continue` **без** delay. `attempt` растёт (cap `MAX_RETRIES` default 20) → не бесконечно, но spam RPC + fee escalate ~×1.15^N. Нет absolute fee/balance re-check на RBF bump path. | RPC hammer + overpay gas |

### 3.2 Medium

| ID | Тема | Где | Детали | Риск |
|----|------|-----|--------|------|
| **M1** | Alchemy full key в IPC | `lib.rs` `SettingsDto::from_session` | UI кладёт в input `""` + masked placeholder (хорошо), но DTO всё равно шлёт **полный** `alchemy_api_key` во frontend. XSS / DevTools / extension = ключ. | Утечка Alchemy key |
| **M2** | `VaultEntry: Debug` печатает key | `types.rs` `#[derive(Debug)]` на `VaultEntry` | `Session` redacted, но `VaultEntry { key }` при `{:?}` / accidental log = plaintext private key. | Утечка PK в логах |
| **M3** | Proxy `host:port:user:pass` fragile | `proxy.rs` `parse_proxy` | `split(':')` ровно 4 части; `:` в password ломает parse. Credentials **не** URL-encode в `http://user:pass@host:port`. Silent drop invalid lines в `from_text` (`.ok()`). | Потеря прокси / wrong auth / fallback direct IP |
| **M4** | primary session unwrap | `mint.rs` L922–923 | После `auth_ok_count > 0` — `find auth_ok).unwrap()` + `session.as_ref().unwrap()`. На текущих путях (cache + SIWE) session всегда `Some` при `auth_ok`; инвариант **не** type-enforced. | Panic при регрессии auth path |
| **M5** | Dry-run cost via f64 + `to::<u128>()` | `mint.rs` L2445–2447 | Display-only, но `max_fee.to::<u128>()` / `calldata_value.to::<u128>()` — panic на overflow (практически rare). Display неточен для huge values. | Dry-run panic edge case |
| **M6** | `mint_running` без RAII | `lib.rs` all gated cmds | `swap(true)` … `store(false)` без `Drop` guard. Panic/unwind между ними → permanent busy. | UI «busy forever» |
| **M7** | Sweep/raw live без typed LIVE | `api.rs` sweep/raw `_confirm` ignored; UI часто `confirm: ""` | Tasks path имеет modal; Sweep ETH/NFT / raw once — другой UX (dry default, но live возможен без typed word). | Operator mistake spend |
| **M8** | AuthCache password `String` | `auth_cache.rs` | Не `Zeroizing`; password живёт в heap до drop. | Residual secret in RAM |

### 3.3 Low / notes

| ID | Тема | Детали |
|----|------|--------|
| **L1** | Vault encrypt `.expect` | `vault.rs` rng/cipher — panic only on catastrophic failure; OK for local app, inconsistent with decrypt `Result`. |
| **L2** | Missing vault = empty entries | `add`/`import` silently create new vault with any password if file absent. Wrong-password on **existing** vault fails correctly. UX surprise on wrong CWD. |
| **L3** | `RpcClient::new` expect | HTTP client build failure panics. Rare. |
| **L4** | edition / clippy allowlist | Documented in older audit; not a runtime bug. |
| **L5** | Hybrid open / funding / mock-RPC | Features still planned (`IMPROVEMENT_PLAN` #4, #7, #10). |
| **N1** | Local `Public/` has live secrets | gitignored — OK. Never zip whole Public; use `package-public.ps1 -MakeZip`. |
| **N2** | Keys in RAM while unlocked | By design; idle auto-lock (default 30m) + Lock button. |

### 3.4 False positives (из aborted Fable-ревью — **не** баги)

| Claim | Почему false |
|-------|----------------|
| Semaphore permit `let _ =` dropped immediately | Code uses `let _p` / `let _permit` — permit held for scope |
| Flashbots err_i / pieces index mismatch | pieces filtered to `Some` before loop |
| priority can exceed max_fee after sniper fee refresh | `calculate_fees` always `mf >= pf`; partial bump cannot violate that |
| Full Alchemy key shown in settings input | UI clears input; only masked placeholder (but **M1** still valid for IPC payload) |

## 4. Hot-path checklist (актуально)

| Step | OpenSea mint | Raw sniper |
|------|--------------|------------|
| Auth | SIWE + encrypted cache flush | N/A |
| Wait open | Wall clock + lag ms | Pre-sign T−5s → clock fire |
| Gas | LIVE fixed-gas + L2 floor | Hard limit / estimate |
| Fees | fee_history @ fire | L1 re-sign if mode allows |
| Send | multi-RPC race / Flashbots | blast pre-signed |
| Confirm | multi-hash RBF (max 3 ×1.30) | receipt wait |
| Success | `Confirmed` only | same |
