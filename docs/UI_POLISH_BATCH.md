# Пояснительная записка: батч UI‑полировки (палитра команд, хоткеи, память сетей)

Пояснительная записка к PR с быстрой полировкой десктопного UI
(`crates/minter-desktop/ui`). Это цельный набор из нескольких небольших,
самодостаточных улучшений оператора + мелкая чистка кодировки. Крупные core‑фичи
из `docs/IMPROVEMENT_PLAN.md` (#4 event‑driven open, #9 метрики латентности,
#10 hot‑path тесты) сюда **не входят** — они пойдут отдельными PR, чтобы каждую
можно было проверить и отревьюить по отдельности.

> **Важно.** Мы сознательно **не трогали горячий путь минта** (loop OpenSea/Raw,
> подпись, отправка). Всё здесь — оболочка: навигация, оверлеи, локальные
> настройки в `localStorage`. Это инструмент, который двигает реальные средства,
> поэтому объём изменений держим узким и проверяемым.

---

## Background

### Совсем с нуля (можно пропустить)

Десктоп — это Tauri‑приложение: нативное окно, внутри — обычная веб‑страница
(`index.html` + `styles.css` + `app.js`, модуль ES). Логика на Rust вызывается из
JS через «команды» (`window.__TAURI__.core.invoke("...")`). Строки интерфейса
живут в `i18n.js` (EN/RU) и подставляются функцией `applyI18n()` по атрибутам
`data-i18n` / `data-i18n-placeholder`.

Навигация между вкладками — функция `navigate(name)` (внутри вызывает
`showPage(name)`), кнопки в сайдбаре помечены `data-page`. Живой минт показывает
оверлей **Mission Control** (`#mission-control`) с функциями
`openMissionControl(title)`, `closeMissionControl()`, `toggleMcMinimize()`.

### Узкий контекст этого PR

Пять точечных вещей, которые напрашивались:

1. Выбор сети в Wallets (`#wallet-balance-chain`) и набор сетей для RPC‑пинга
   сбрасывались при каждом запуске.
2. `Escape` закрывал только модалку подтверждения — свернуть Mission Control с
   клавиатуры было нельзя, как и открыть его заново после закрытия.
3. RPC‑пинг всегда бил по фиксированным 6 сетям (бэкенд, впрочем, уже умеет
   принимать произвольный список — см. `Api::probe_networks`).
4. Не было быстрого перехода по вкладкам с клавиатуры.
5. В `styles.css` в комментариях лежали 5 «битых» байтов `0x97`
   (Windows‑1252 тире) — невалидный UTF‑8.

## Intuition

Вся суть — «сделать оболочку приятнее, ничего не трогая в двигателе».

- **Память сетей.** Уже есть паттерн: онбординг помнит показ через
  `localStorage`. Применяем тот же приём к двум селекторам сети — читаем при
  загрузке, пишем на `change`.
- **Клавиатура для Mission Control.** Один глобальный слушатель `keydown`.
  `Esc` сворачивает HUD (если открыт и ничего важнее не перехватывает Esc),
  `Ctrl/Cmd+M` открывает его заново (запоминаем последний заголовок в
  `lastMcTitle`).
- **Палитра команд (Ctrl/Cmd+K).** Оверлей со списком, который строится «на лету»
  прямо из пунктов сайдбара (`.nav-item[data-page]`) — значит, метки уже
  переведены и всегда синхронны с меню — плюс пара действий. Стрелки двигают
  выбор, `Enter` запускает, `Esc` закрывает.
- **Пофайловый выбор сетей RPC.** Чекбоксы‑«пилюли»; выбранные значения уходят в
  `probe_networks({ chains })`. Пусто → бэкенд берёт свои дефолты.

Игрушечный пример: оператор пингует только Base и Robinhood — снимает лишние
галочки один раз, они сохраняются, и следующий пинг бьёт ровно по двум сетям.

## Code

Изменения — в четырёх файлах UI. Rust не затронут.

**1. `index.html`** — разметка палитры (перед `#modal-overlay`), полоса чекбоксов
сетей на странице RPC и иконка‑часы в заголовке «Last mint run»:

```html
<div id="cmd-palette" class="cmd-overlay hidden" role="dialog" aria-modal="true">
  <div class="cmd-card">
    <input id="cmd-input" class="cmd-input" data-i18n-placeholder="cmd.placeholder" />
    <ul id="cmd-list" class="cmd-list" role="listbox"></ul>
    <div class="cmd-foot muted small"><span>↑↓</span> select · <span>↵</span> open · <span>Esc</span> close</div>
  </div>
</div>
```

> **Тонкость с i18n.** `applyI18n()` перезаписывает `textContent` элемента с
> `data-i18n`. Поэтому иконку в заголовке нельзя класть внутрь элемента с
> `data-i18n` — она бы стёрлась. Решение: `data-i18n` вешаем на **вложенный**
> `<span>`, а иконку держим соседним узлом.

**2. `styles.css`** — стили палитры (`.cmd-*`), «пилюль» сетей (`.chip-check`,
`.rpc-chain-picker`), заголовка панели (`.panel-title`), и чистка 5 байтов:

```css
.cmd-item.active { background: var(--card-hover); outline: 1px solid var(--accent-border); }
.chip-check { border: 1px solid var(--border); border-radius: 999px; padding: 3px 10px 3px 8px; }
```

**3. `app.js`** — самодостаточный блок в конце файла (чтобы не переплетаться с
существующим кодом):

```js
// persist balance chain + RPC chain selection via localStorage
// selectedRpcChains() -> array | null
// command palette: buildCmdItems() из .nav-item[data-page] + действия
// global keydown: Ctrl/Cmd+K, Ctrl/Cmd+M, Esc → collapse MC
```

Плюс две точечные правки: `openMissionControl` запоминает `lastMcTitle`, а вызов
`probe_networks` теперь передаёт `chains: selectedRpcChains()` вместо `null`.

**4. `i18n.js`** — ключи `cmd.*` и `rpc.pingWhich` в EN и RU.

## Verification

Проверял в headless‑Chromium (Playwright). Так как `app.js` — ES‑модуль, его
нельзя грузить с `file://` (CORS), поэтому UI отдавался локальным HTTP‑сервером, а
мост Tauri (`window.__TAURI__`) подменялся заглушкой, чтобы модуль отработал.

| Проверка | Результат |
|---|---|
| Ctrl+K открывает палитру | ✅ 15 пунктов (12 вкладок + 3 действия) |
| Фильтр «raw» | ✅ остаётся «Raw Mint» |
| ↵ переходит на вкладку и закрывает палитру | ✅ |
| Esc сворачивает Mission Control | ✅ `mc-collapsed` |
| Ctrl+M открывает MC заново | ✅ |
| Чекбоксы сетей RPC | ✅ 10 шт, 6 отмечены по умолчанию |
| Память сети (Wallets) | ✅ пишется `minter_balance_chain=base` |
| Ошибки страницы в консоли | ✅ нет |

`node --check` для `app.js`/`i18n.js` — без ошибок; `styles.css` — валидный UTF‑8.
Скриншоты палитры, страницы RPC и Home приложены в тред. Ручная проверка: собрать
десктоп, `Ctrl+K` → перейти на вкладку; на RPC снять часть галочек и «Ping»;
сменить сеть в Wallets и перезапустить — выбор сохранился.

## Alternatives

**Палитра: строить список статически vs из DOM сайдбара.**

| Из DOM (`.nav-item`) — выбрано | Статический список |
|---|---|
| Метки уже переведены, всегда синхронны с меню | Полный контроль над порядком/группами |
| Нулевое дублирование | Нужно руками поддерживать при новых вкладках |
| Иконки берём из тех же `.nav-ico` | Риск рассинхрона меток при смене языка |

**Персистентность: `localStorage` vs файл конфигурации (Rust).**

| `localStorage` — выбрано | Через `config.json` (invoke) |
|---|---|
| Не трогает бэкенд, нулевой риск | Переживает переустановку/очистку кэша |
| Мгновенно, синхронно | Требует новых команд + сериализации |
| Достаточно для UI‑предпочтений | Избыточно для «последней выбранной сети» |

## Quiz

<details>
<summary>1. Почему список палитры строится из <code>.nav-item[data-page]</code>, а не задаётся статически?</summary>

- **A. (верно)** Пункты сайдбара уже локализованы и всегда актуальны — палитра не
  дублирует метки и не рассинхронизируется при добавлении вкладок или смене языка.
- **B.** Потому что статические массивы не поддерживаются в модулях.
- **C.** Чтобы обойти CSP.
</details>

<details>
<summary>2. Что случится с иконкой, если повесить <code>data-i18n</code> на сам <code>&lt;h3&gt;</code> заголовка?</summary>

- **A.** Ничего, иконка сохранится.
- **B. (верно)** `applyI18n()` перезапишет `textContent` всего `h3` и удалит
  вложенный `<svg>`. Поэтому `data-i18n` вешается на отдельный вложенный `<span>`.
- **C.** Иконка станет чёрной.
</details>

<details>
<summary>3. Что передаётся в <code>probe_networks</code>, если оператор снял все галочки сетей?</summary>

- **A.** Пустой массив, и ничего не пингуется.
- **B. (верно)** `selectedRpcChains()` вернёт `null`, и бэкенд применит свои
  дефолтные 6 сетей (`Some(c) if !c.is_empty()` не сработает → ветка по умолчанию).
- **C.** Ошибка «нет сетей».
</details>

<details>
<summary>4. Почему для проверки JS пришлось поднимать HTTP‑сервер и подменять <code>window.__TAURI__</code>?</summary>

- **A. (верно)** `app.js` — ES‑модуль; Chromium не грузит модули с `file://`
  (CORS). А без заглушки Tauri модуль падает на `window.__TAURI__.core`, и
  слушатели (палитра, хоткеи) не навешиваются.
- **B.** Потому что Playwright не умеет открывать локальные файлы.
- **C.** Чтобы обойти проверку пароля vault.
</details>

<details>
<summary>5. Почему Esc‑обработчик проверяет открытые модалки и палитру перед сворачиванием Mission Control?</summary>

- **A.** Для скорости.
- **B. (верно)** Чтобы не «красть» Esc: если открыта палитра или модалка
  подтверждения/онбординга, Esc должен закрывать их, а не сворачивать HUD.
- **C.** Esc вообще не работает в Tauri, проверка формальна.
</details>
