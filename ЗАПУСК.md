## Git: куда пушить

| Правило | |
|---------|--|
| **Push только сюда** | `https://github.com/Anda4ka/minter-rs` |
| **Ветка** | `main` (default; другие ветки на remote не держим без нужды) |
| **Не пушить** | `Anda4ka/MINTER`, `Minter-privat` и прочие remotes — **не** основной продукт, если явно не решено иначе |

```powershell
# проверить remote
git remote -v
# push (имя remote: origin или viktor — смотри URL)
git push <remote> main
```

Секреты (`Public\keys.vault`, `config.json`, `.env`, logs/results) в git **не** коммитить.

## Совсем коротко

1. Откройте папку **`Public\`**.  
2. Запустите **`minter-desktop.exe`**.  
3. Unlock vault (burner only + пароль).  
4. **Wallets** → импорт ключей → (опц.) **Network** + **Check balances**.  
5. **Settings** → Alchemy API key (private) / RPC → Save → **RPCs** → **Ping networks**.  
6. (Желательно) **Proxies** → список → Save.  
7. **Tasks** → slug → **фаза** → **кошельки** → **Start** (LIVE + type **`LIVE`**; HUD Mission Control).  
8. **Raw Mint** — multi-wallet contract (`mint(uint256)` / Discover) — см. ИНСТРУКЦИЯ.

**Success = CONFIRMED в блоке.** `SENT` — ещё не победа.  
Open фазы: **wall clock**. LIVE OpenSea: **fixed gas** (estimate на open не блокирует).

## Сборка из исходников

После правок кода (из **корня** клона `minter-rs`):

```powershell
# из корня репо
powershell -ExecutionPolicy Bypass -File scripts\package-public.ps1
.\Public\minter-desktop.exe
```

Скрипт: `cargo build -p minter-desktop --release` → копирует exe в `Public\`.  
Не затирает vault / config / tasks.

После merge/push — только в **https://github.com/Anda4ka/minter-rs** (`main`).

Освободить диск после package:

```powershell
Remove-Item -Recurse -Force target
```

Тесты:

```powershell
cargo test -p minter-core
```
