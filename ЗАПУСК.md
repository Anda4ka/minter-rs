## Совсем коротко

1. Откройте папку `Public\` (или распакуйте zip).
2. Запустите **`minter-desktop.exe`**.
3. Unlock vault (burner only + пароль).
4. **Wallets** → импорт ключей.
5. **Settings** → Alchemy/RPC → Save → **RPCs** → Probe.
6. **Tasks** → Create task → **Start** (LIVE сразу, без CONFIRM).

Start = **LIVE**: sim → send если ок → success только после on-chain confirm.

Сборка из исходников:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-public.ps1
.\Public\minter-desktop.exe
```
